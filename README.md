# KnightFall

KnightFall is a 2D side-scrolling game built in Unity.
This medieval style game allows you to fight enemies,
and loot chests, buy items to aid you in combat, level
up your character and expand your skilltree, explore
the environment and discover hidden levels.

## Features
- Enemies
- Combat System
- Title Screen
- Item Shop
- Map
- Player Inventory
- Interactable Environment
- Item / Potion Usage
- Currency System
- Player UI
- Player Death & Respawn
- XP and Leveling
- Player Movement
- Puzzles

## Controls
- Move: A / D
- Jump: Space
- Attack: E
- Open inventory: TAB
- Interact: Q / LeftMouseClick
- Shop Interact: Q

## Requirements
- Unity (version: 6000.5.5f1)

## How to Run
1. Clone the repo
2. Open the `KnightFall` folder as a project in Unity Hub
3. Open the main scene
4. Set aspect ratio to Full HD (1920 x 1080)
5. Set scale to anything less than 1 to fit your computer
6. Hit play and enjoy the game
